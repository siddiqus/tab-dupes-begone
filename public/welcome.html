Tab Dupes Begone

Already open? Switch to it instead of opening a duplicate.

What it does

When you open a page you already have open in another tab, Tab Dupes Begone switches you to that tab instead of opening a second copy. You choose below which kinds of links and actions this applies to. Matching is by exact URL, and duplicates you make on purpose (such as right-click → Duplicate) are left alone.

Why Chrome said “Read and change all your data on all websites”

To tell what kind of link you clicked, the extension runs a small script on web pages. That script only notices link clicks: which link, which modifier keys you held, and whether it opens in a new tab. It uses that to decide whether to switch tabs.

  • It never reads page content.
  • Only the last link clicked in each tab is remembered, in session storage, until the tab closes.
  • Your switch settings sync with your Chrome profile. Nothing else leaves your device.

The code is open source: github.com/siddiqus/tab-dupes-begone.
